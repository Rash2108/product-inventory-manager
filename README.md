# Product Inventory Manager

A TypeScript-based Product Inventory Manager developed as part of the Advanced Web Technologies (24MCA301) assignment.

## Project Structure

The project is divided into two parts.

### PART-A – TypeScript

This section demonstrates the TypeScript concepts covered in Module 1:

- Basic Types and Variables
- Union Types
- Functions
- Default Parameters
- Array `map()` method
- Block Scope
- Interfaces
- Optional Properties
- Interface Extension
- TypeScript Compilation
- Type Errors and Debugging
- `tsconfig.json`

### PART-B – Product Inventory Manager

A browser-based inventory management application developed using HTML, CSS, JavaScript and TypeScript concepts.

Features:

- Add Product
- Display Products
- Search Products
- Remove Product
- Stock Status
- Product Tags
- Product Count

## Technologies Used

- TypeScript
- JavaScript
- HTML5
- CSS3
- Node.js
- TypeScript Compiler
